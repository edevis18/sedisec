# SEDISEC — Brochure web corporativo

Sitio estático responsive, listo para previsualizar y publicar en un hosting web.

## Cómo abrirlo
1. Descomprima el archivo ZIP.
2. Abra `index.html` en su navegador.
3. Para publicar, suba el contenido de la carpeta al directorio público (`public_html`, `www` o similar) de su hosting.

## Archivos
- `index.html`: contenido del sitio, SEO básico y estructura de secciones.
- `styles.css`: estilo visual responsive.
- `script.js`: menú móvil, slider automático/manual y animaciones.
- `assets/logo.svg`: símbolo conceptual provisional SEDISEC.
- `assets/favicon.svg`: icono provisional para el navegador.
